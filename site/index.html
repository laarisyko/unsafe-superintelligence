The problem
Today's AI is controlled by the few.
Training a frontier model costs hundreds of millions of dollars and requires massive centralized data centers. That means a handful of companies decide what AI can do, who gets access, and what it learns.
🏢

Concentrated power

A few corporations control the most capable AI models. They choose the training data, the safety filters, and who gets API access.

🔒

Walled gardens

Even "open-weight" models were trained behind closed doors. You can use the result but have zero say in what it becomes next.

⚡

Wasted compute

Millions of GPUs around the world sit idle most of the time — gaming rigs, research clusters, cloud instances. That is enough to train frontier models, if we could coordinate.

The solution
A swarm that trains itself.
USSI turns thousands of independent machines into one collective brain. No master node. No central server. Just peers talking to peers.
1

Your agent joins the swarm

Three lines of Python. Your machine connects to nearby peers via a distributed hash table — the same technology that powers BitTorrent.

2

The model is split across peers

No single machine needs to hold the full model. Each peer holds a slice. Inference flows through the pipeline like a relay race.

3

Training happens together

Any peer can start a training round. Others join voluntarily. Gradients are shared in a ring — no server in the middle collecting them.

4

Everyone verifies the result

After each round, every peer independently checks a cryptographic fingerprint of the weights. If they match, the round succeeded. No trust required.

Something new
The model evolves itself — together.
USSI doesn't just train weights. The swarm can collaboratively change the model's architecture. Add layers, widen dimensions, swap activations — all decided by democratic vote.

Propose → Evaluate → Vote → Evolve

Any agent can propose a structural mutation. Every peer independently tests it on their local data. If a majority sees improvement, the mutation is accepted and weights are migrated automatically. No committee. No bureaucracy. Just results.

This is neural architecture search running on a decentralized swarm — something that has never been done before.

Add layers Widen dimensions Swap activations Skip connections Remove bottlenecks
evolve.py
from ussi import Agent # Join the swarm. agent = Agent(bootstrap="/ip4/.../p2p/Qm...") agent.contribute(gpu_memory="8GB") # Propose: make the model deeper. agent.evolve( model="ussi-7b", mutation_type="add_layer", position=12, layer_type="attention", input_dim=4096, output_dim=4096, ) # The swarm votes.
